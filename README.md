# Portfolio with Astro

- **Component-based** — the single `index.html` is split into reusable `.astro` components (`src/components/`) and a shared `Layout.astro`.
- **Content-driven** — page data lives in typed modules under `src/data/`; blog posts are Markdown in `src/content/blog/` managed via Astro content collections.
- **Real routing** — `/` plus per-post pages at `/blog/[slug]`, with a sitemap generated by `@astrojs/sitemap`.
- **Client state** — interactive UI state handled with a small [zustand](https://github.com/pmndrs/zustand) store (`src/stores/ui.ts`).
- **Static output** — `astro build` emits a fully static site to `dist/`, deployable to any static host.

## Prerequisites

- [Node.js](https://nodejs.org) `>=22.12.0`
- [Bun](https://bun.sh) (used as the package manager and test runner)

## Getting started

```bash
git clone https://github.com/alessandropier/alessandropier.github.io
cd alessandropier.github.io
bun install
bun run dev
```

The dev server runs at `http://localhost:4321`.

## Scripts

| Command | Description |
| --- | --- |
| `bun run dev` | Start the Astro dev server |
| `bun run build` | Build the static site to `dist/` |
| `bun run preview` | Preview the production build locally |
| `bun run check` | Type-check the project with `astro check` |
| `bun test` | Run the test suite |

## Project structure

```
src/
  components/   UI split into .astro components
  layouts/      Shared page shell (Layout.astro)
  pages/        Routes — index.astro, blog/[slug].astro
  content/      Markdown blog posts (content collection)
  data/         Typed site content (profile, about, resume, portfolio, ...)
  stores/       Client-side state (zustand)
  scripts/      Browser-side TS entrypoints
public/         Static assets served as-is
```

## Configuration

Set your production URL in `astro.config.mjs` (`site`).
