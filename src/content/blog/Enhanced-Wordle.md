### 💡 About 
---
**Enhanced Wordle** is a fully featured, offline desktop implementation of the Wordle game supporting Italian, English and Spanish, built with Java Swing, featuring dynamic difficulty with variable word lengths and attempts, custom vocabulary management, custom UI rendering and an advanced hint system.

### 📄 How it Started
---
Initially, this was created for my **Software Engineering** university course. The goal was to build a simple implementation of the *Wordle* game *(in Italian)* via Command Line Interface **(CLI)** using the **Agile SCRUM** framework, **GitHub Actions** for **CI/CD** and **Git** for **version control**.

### 🕹️ Features
---
Subsequently, I continued the project to integrate additional features such as:
- **3 Languages** allowing users to pick a language between **Italian**, **English** and **Spanish**.
- **Complete User Interface** built with *Java Swing* and *FlatLaf*.
- A **persistent UI theme preference** system that allows users to toggle between *day and night modes*, automatically saving their selection across sessions.
- **Automatic** and ***random generation*** of the *word to guess* using *built-in dictionaries*.
- **Dictionary validation** system that verifies input length, allowed characters, and checks against the corresponding dictionary to ensure only *valid words* are submitted.
- **Custom dictionaries** feature that enables users to add new words and expand the game's vocabularies.
- **Dynamic difficulty selection** featuring variable *word lengths* and *number of attempts*.
- **Hints** given to the user, randomly selected from *3 categories* based on their current context.

For more details about the project, to play the game, or to view the source code, check out the GitHub repository or the Demo YouTube video.
